## 🚀 Getting Started

Each day's folder contains the code for that lesson. To run a project:

```bash
# Navigate to a specific day
cd Day01

# Run the main script
python main.py
```

For projects with multiple files (like Snake Game or Pong), they're organized in the day folder with separate modules.
